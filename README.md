# Diffory

Application de revue Git multi-dépôts pour macOS, Windows et Linux.

[Télécharger la dernière version](https://github.com/Dylan-Mastrolia-univ/diffory-releases/releases/latest)

Choisissez le fichier adapté :

- macOS Apple Silicon : `darwin_aarch64.dmg`.
- macOS Intel : `darwin_x86_64.dmg`.
- Windows x64 : `windows_x86_64-setup.exe`.
- Linux x64 : `linux_x86_64.AppImage` ou `linux_x86_64.deb`.

À partir de Diffory 1.1.0, l’application propose les nouvelles versions au démarrage et les installe après votre accord. Une recherche manuelle est disponible dans les préférences. La version 1.0.0 demande une première installation manuelle de 1.1.0.

Les paquets de mise à jour sont signés et vérifiés avant installation. Les versions macOS utilisent actuellement une signature ad hoc et ne sont pas notarisées par Apple. Les licences sont embarquées dans chaque application.

Ce dépôt contient les installateurs et les mises à jour. Le développement du code source est géré séparément.
